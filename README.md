### 🌐 Cara Mengaktifkan GitHub Pages (Live Demo)
Jika Anda menyalin repository ini dan ingin mengaktifkan halaman website agar bisa diakses publik secara gratis lewat GitHub Pages, ikuti langkah berikut:

1. Masuk ke halaman repository ini di GitHub Anda.
2. Klik tab **Settings** di bagian menu atas.
3. Di bilah menu sebelah kiri, cari dan klik bagian **Pages**.
4. Pada bagian **Build and deployment** -> **Source**, pastikan terpilih opsi `Deploy from a branch`.
5. Di bawah menu **Branch**, ubah pilihan dari `None` menjadi `main` (atau `master`), lalu biarkan folder pada posisi `/ (root)`.
6. Klik tombol **Save**.
7. Tunggu sekitar 1-2 menit, lalu segarkan halaman. Tautan *Live Website* Anda akan muncul di bagian atas halaman pengaturan tersebut!
